The word is **Cookies**. Everyone on the internet has clicked "Accept" on a cookie banner, and tracking cookies are the quiet machinery underneath the ad-funded web — so one word captures both the joke and the whole internet at once.

## How to run

```sh
python3 main.py
```

It writes exactly one word, no trailing newline, to /output/entry.txt. Pure Python 3.13 standard library, deterministic — the same bytes on every run.
